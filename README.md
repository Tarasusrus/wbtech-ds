# Data Science: конспекты и практика

Рабочая тетрадь к курсу «Специалист по Data Science» (WB Техношкола):
конспекты тем и практика в Jupyter на синтетических данных с автопроверками.

Цель — не сдать задание, а **понять каждый термин и каждую формулу**: реализовать её
руками, сверить с библиотекой, сломать и объяснить своими словами.

> Неофициальный проект студента, не связан с Wildberries. Конспекты написаны своими
> словами, материалы курса здесь не воспроизводятся. Пригодится и тем, кто курс не проходит.

- `practice.ipynb` — практика.

### Как устроена практика

| Значок | Что делать |
|---|---|
| 🧩 **Задание** | Написать код вместо `...` |
| ✅ **Проверка** | Запустить и не трогать. Упала — ищи ошибку в решении |
| ❓ **Объясни** | Ответить текстом. Обязательная часть |
| 🚀 **Расширение** | По желанию: копнуть глубже |

Проверки ловят типичные ошибки, а не только опечатки: деление на `n` вместо `n−1`,
строгое неравенство в ECDF, ошибку float в `floor(100·0.29)`, гистограмму без
учёта ширины интервала и так далее.

### Сквозные данные

Весь раздел «Статистика» работает на одном синтетическом маркетплейсе — миллионе
заказов за месяц (`src/ds_course/marketplace.py`). Законы, по которым он
сгенерирован, известны, поэтому **любую оценку можно сверить с истиной**. В
реальной работе такой роскоши нет, а для учёбы это лучший способ увидеть, что
такое смещение, состоятельность или нерепрезентативная выборка.

## Быстрый старт

Нужен Python 3.12+.

```bash
git clone https://github.com/Tarasusrus/wbtech-ds.git
cd wbtech-ds

# вариант 1: uv (рекомендуется)
uv sync

# вариант 2: pip
python -m venv .venv && source .venv/bin/activate
pip install -e .
```

Открой `course/05_statistics/01_theoretical_and_sample_characteristics/` в Jupyter,
VS Code или PyCharm. Ядро — интерпретатор `.venv` проекта. Сначала прочитай
`README.md` темы, затем решай `practice.ipynb` сверху вниз.

## Где хранить свои решения

Решай в **своей ветке**, тогда шаблоны в `main` остаются чистыми, а обновления
подтягиваются без конфликтов:

```bash
git switch -c my-solutions        # один раз
# ... решаешь, коммитишь в my-solutions ...

git switch main && git pull       # вышли новые темы
git switch my-solutions && git merge main
```

Если делаешь форк, ветку с решениями лучше не пушить: следующим студентам полезнее
дойти до ответа самим.

## Участие

Нашёл ошибку в формуле, неточность в конспекте или проверку, которая пропускает
неверное решение? Открой issue или PR. Особенно ценны правдоподобные неверные
решения, которые проходят проверку.

Тесты генератора данных: `uv run pytest`. Они следят, чтобы существующие данные
не менялись: пороги проверок в тетрадках подобраны именно под них.
