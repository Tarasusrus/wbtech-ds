# 5.1 Теоретические и выборочные характеристики

> Конспект урока курса своими словами + то, что всплыло при проверке формул в коде.
> Практика: [`practice.ipynb`](practice.ipynb) — на сквозных данных маркетплейса.

## Тема одной фразой

Всю генеральную совокупность мы не видим, видим только **выборку**. По выборке мы
считаем **оценки** неизвестных **параметров**. Вся тема о том, когда такой оценке
можно верить.

---

## 1. Задача оценивания: три объекта

| Объект | Обозначение | Случайный? | Пример на маркетплейсе |
|---|---|---|---|
| **Параметр** | $\theta$ | **Нет.** Это фиксированное число, мы его просто не знаем | Средний чек всех заказов за месяц |
| **Наблюдения (выборка)** | $X_1, \dots, X_n$ | **Да.** Каждый раз попадают разные заказы | Чеки 500 случайно выбранных заказов |
| **Оценка** | $\hat\theta_n = g(X_1,\dots,X_n)$ | **Да.** Это функция от случайных величин | Среднее этих 500 чеков |

Главная мысль: **оценка тоже случайная величина.** Возьмёшь другую выборку и получишь
другое число. Поэтому мы спрашиваем не «правильная ли оценка», а «как она себя
ведёт в среднем и при росте $n$».

Формально оценкой можно назвать любую функцию от выборки, даже константу
«всегда 1500 ₽». Отличить хорошие оценки от плохих помогают три свойства.

## 2. Три свойства хорошей оценки

### Несмещённость (unbiased)

$$M[\hat\theta_n] = \theta$$

В среднем по всем возможным выборкам оценка попадает в параметр: нет
систематического завышения или занижения.
**Смещение** (bias) — это $M[\hat\theta_n] - \theta$.

### Состоятельность (consistent)

$$\hat\theta_n \xrightarrow[n\to\infty]{P} \theta
\quad\Longleftrightarrow\quad
\forall \varepsilon>0:\; P\big(|\hat\theta_n-\theta|>\varepsilon\big)\to 0$$

Чем больше данных, тем реже оценка промахивается больше чем на $\varepsilon$.
**Это обязательное свойство.** Несмещённость желательна, но иногда ею жертвуют.

- Константа «1500» несостоятельна: она вообще не смотрит на данные.
- Выборочная дисперсия с делителем $n$ смещена, но состоятельна.
- ⚠️ Состоятельность всегда считается **относительно конкретного параметра**.
  Выборочная медиана состоятельна для медианы. Для матожидания скошенного
  распределения (как чек) она несостоятельна: сходится к другому числу.

### Эффективность (efficient)

Из нескольких несмещённых оценок одного параметра лучшая та, у которой
**минимальная дисперсия**. В общем случае оценки сравнивают по
среднеквадратической ошибке:

$$\mathrm{MSE}(\hat\theta_n) = M\big[(\hat\theta_n-\theta)^2\big]
= \underbrace{D[\hat\theta_n]}_{\text{разброс}} + \underbrace{\big(M[\hat\theta_n]-\theta\big)^2}_{\text{смещение}^2}$$

У несмещённой оценки второе слагаемое равно нулю, и её MSE совпадает с дисперсией.

<details><summary>Вывод разложения MSE (полезно один раз сделать руками)</summary>

Обозначим $m = M[\hat\theta]$. Добавим и вычтем $m$:

$$(\hat\theta-\theta)^2 = (\hat\theta - m)^2 + 2(\hat\theta-m)(m-\theta) + (m-\theta)^2$$

Возьмём матожидание. $(m-\theta)$ — константа, а $M[\hat\theta - m] = 0$, поэтому
среднее слагаемое исчезает:

$$M[(\hat\theta-\theta)^2] = D[\hat\theta] + (m-\theta)^2 \quad\blacksquare$$
</details>

Эффективные оценки даёт **метод максимального правдоподобия**, если известен
закон распределения. В курсе мы его не выводим и пользуемся готовыми оценками.

| Свойство | Вопрос, на который отвечает | «Глупая» оценка 1500 ₽ |
|---|---|---|
| Несмещённость | Нет ли систематического перекоса? | Смещена |
| Состоятельность | Растёт ли точность с ростом $n$? | Нет |
| Эффективность | Самая ли она точная среди несмещённых? | Не участвует: смещена |

## 3. Генеральная совокупность и выборка

- **Генеральная совокупность** (population) — всё множество объектов, о котором
  мы хотим что-то узнать. Например, все заказы за месяц.
- **Выборка** — те объекты, которые мы реально наблюдаем.
- **Репрезентативность** — выборка похожа на совокупность. Нужны два условия:
  1. **достаточный объём**;
  2. **случайность**: у каждого объекта одинаковый шанс попасть в выборку.

⚠️ Эти условия не заменяют друг друга. Если отбор неслучайный (скажем, только
заказы из приложения), то **рост $n$ смещение не лечит**: оценка уверенно
сходится к неправильному числу. Состоятельность обещана только при случайном
отборе.

## 4. Пары «теоретическая ↔ выборочная»

**Теоретическая** (популяционная) характеристика описывает всю совокупность и
неизвестна. **Выборочная** характеристика считается по данным и служит её
**точечной оценкой**. В речи слово «выборочная» обычно опускают, отсюда путаница.

Обозначения: теоретическую характеристику пишут греческой буквой ($\mu, \sigma^2$),
оценку — той же буквой со «шляпкой» ($\hat\mu, \hat\sigma^2$) или с чертой
($\overline X$). $M \equiv E$ — матожидание (в русской и английской традиции),
$D \equiv \mathrm{var}$ — дисперсия.

| Что оцениваем | Теоретическая | Выборочная оценка |
|---|---|---|
| Центр | $\mu = M[X] = \int x f(x)\,dx$ (дискретная: $\sum x_i p_i$) | $\overline X = \frac1n\sum X_i$ |
| Разброс | $\sigma^2 = D[X] = M[(X-M X)^2]$ | $S^2 = \frac1n\sum (X_i-\overline X)^2$ или $s^2 = \frac1{n-1}\sum (X_i-\overline X)^2$ |
| Стандартное отклонение | $\sigma = \sqrt{D[X]}$ | $S$ или $s$ |
| Вероятность / доля | $p = P(A)$ | $\hat p = m_A / n$ (частота) |
| Закон распределения | $F(x) = P(X\le x)$ | $\hat F_n(x)$ (раздел 5) |
| Квантиль | $x_\alpha$ | $\hat x_\alpha = X_{([n\alpha]+1)}$ (раздел 5) |
| Плотность | $f(x)$ | гистограмма, KDE (раздел 6) |

### Почему делят на $n-1$

$$M[S^2] = \frac{n-1}{n}\sigma^2$$

Отклонения считаются от $\overline X$, а не от истинного $\mu$. Выборочное среднее
по построению ближе всего к своим же точкам, поэтому $\sum(X_i-\overline X)^2$ в
среднем меньше, чем $\sum(X_i-\mu)^2$. Делитель $n-1$ компенсирует это занижение:
$s^2$ несмещённая. Обе оценки состоятельны, и при больших $n$ разница исчезает.

### ⚠️ `ddof`: одни и те же данные, разные ответы

`ddof` (delta degrees of freedom) — это делитель $n - \text{ddof}$.

| Вызов | По умолчанию | Что считает |
|---|---|---|
| `np.var(x)`, `np.std(x)` | `ddof=0` | $S^2$, делитель $n$ |
| `pd.Series.var()`, `.std()` | `ddof=1` | $s^2$, делитель $n-1$ |
| `statistics.variance` / `pvariance` | $n-1$ / $n$ | |

## 5. Вариационный ряд, порядковые статистики, ECDF, квантили

**Вариационный ряд** — выборка, отсортированная по возрастанию:
$X_{(1)} \le X_{(2)} \le \dots \le X_{(n)}$.
**Порядковая статистика** $X_{(k)}$ — $k$-й по величине элемент. Это тоже
случайная величина. $X_{(1)}$ — минимум выборки, $X_{(n)}$ — максимум.

**Выборочная (эмпирическая) функция распределения** (ECDF):

$$\hat F_n(x) = \frac{\#\{i : X_i \le x\}}{n}
=\begin{cases}0, & x < X_{(1)}\\ k/n, & X_{(k)}\le x< X_{(k+1)}\\ 1, & x\ge X_{(n)}\end{cases}$$

- График — ступеньки высотой $1/n$. Если значение повторяется $r$ раз, ступенька
  в этой точке высотой $r/n$.
- ⚠️ Неравенство **нестрогое** ($\le$): в точке наблюдения функция уже сделала скачок.
- Состоятельна: при росте $n$ сходится к $F(x)$, причём равномерно по всем $x$
  (теорема Гливенко–Кантелли).

**Насколько ECDF далека от истины — расстояние Колмогорова:**

$$D_n = \sup_x \big|\hat F_n(x) - F(x)\big|$$

Где искать максимум: между соседними точками выборки $\hat F_n$ постоянна, а $F$
растёт. Поэтому $\sup$ достигается **в точках выборки**, с одной из двух сторон
скачка:
- справа: $|\hat F_n(X_{(k)}) - F(X_{(k)})|$;
- слева: $|\hat F_n(X_{(k)}-0) - F(X_{(k)}-0)|$, где $G(x-0)$ — значение «чуть левее $x$»,
  то есть доля элементов строго меньше $x$.

Гливенко–Кантелли: $D_n \to 0$ с вероятностью 1.

**Выборочная квантиль уровня $\alpha$** (формула курса):

$$\hat x_\alpha = X_{([n\alpha]+1)}$$

где $[\cdot]$ — целая часть. Квантиль 0,5 — это выборочная медиана.

⚠️ Что выяснилось при проверке в коде:

1. **Без повторов в выборке формула курса = наименьший $X_{(k)}$, у которого $\hat F_n > \alpha$ (строго).**
   В `np.quantile(method="inverted_cdf")` условие нестрогое: $\hat F_n \ge \alpha$.
   Поэтому ответы совпадают, только когда $n\alpha$ не целое. При $n=100,\ \alpha=0{,}9$
   курс даёт $X_{(91)}$, а `inverted_cdf` — $X_{(90)}$. Метода, который совпадал бы
   с формулой курса **всегда**, в `np.quantile` нет. С повторами $\hat F_n(X_{(k)})$ уже не равно $k/n$,
   и это правило «через $\hat F_n$» может разойтись с формулой. Источник истины — сама формула.
2. По умолчанию (`method="linear"`) numpy и pandas **интерполируют** между
   соседними порядковыми статистиками. Это третий вариант ответа.
3. **Ловушка float:** `100 * 0.29` даёт `28.999999999999996`, и `floor` возвращает
   28, а не 29. Наивная реализация формулы ошибается на целых $n\alpha$.

## 6. Оценка плотности: гистограмма и KDE

### Гистограмма

Если в $j$-й интервал шириной $\Delta_j$ попало $n_j$ наблюдений, высота столбика

$$h_j = \frac{n_j}{n\,\Delta_j}$$

Тогда **площадь** столбика равна доле $n_j/n$, а общая площадь равна 1, как у
плотности. ⚠️ Частоте пропорциональна **площадь**, а не высота. При неравных
интервалах высота $n_j/n$ без деления на $\Delta_j$ искажает картину.
Минус гистограммы: изломы на границах интервалов, которых у настоящей плотности нет.

### Ядерная оценка плотности (KDE)

$$\hat f_n(x) = \frac{1}{nh}\sum_{i=1}^{n} K\!\left(\frac{x-X_i}{h}\right)$$

Над каждым наблюдением ставится маленький «холмик» $K$ ширины $h$, и все холмики
складываются.

Требования к ядру $K$: чётное, $K\ge0$, $\int K = 1$.

| Ядро | $K(u)$ при $\lvert u\rvert\le1$ (вне — 0) |
|---|---|
| Прямоугольное | $1/2$ |
| Треугольное | $1-\lvert u\rvert$ |
| Епанечникова | $\frac34(1-u^2)$ |
| Гауссово (на всей оси) | $\frac{1}{\sqrt{2\pi}}e^{-u^2/2}$ |

- **Выбор $h$ важнее выбора ядра.** Маленькое $h$ даёт ложные пики (недосглаживание),
  большое $h$ размывает настоящие моды (пересглаживание).
- При ручном подборе начинают с малого $h$ и увеличивают, пока не исчезнут
  ложные пики.
- ⚠️ В `scipy.stats.gaussian_kde(x, bw_method=c)` число `c` — это не $h$,
  а множитель: $h = c\cdot s$, где $s$ — выборочное стандартное отклонение (`ddof=1`).

**Как измерить качество KDE**, если истинная плотность $f$ известна (в учебных
данных — да, в жизни — нет) — интегральная квадратичная ошибка:

$$\mathrm{ISE}(h) = \int \big(\hat f_h(x) - f(x)\big)^2\,dx$$

Лучшее $h$ — то, при котором ISE минимальна. В жизни $f$ неизвестна, поэтому
$h$ берут по правилу. Самое известное — **правило Сильвермана** (оптимально,
если данные близки к нормальным):

$$h \approx 1{,}06 \cdot s \cdot n^{-1/5}$$

## 7. Как это в коде

Всё, что нужно для практики сверх теории. Проверки в тетрадке не требуют ничего,
чего нет здесь или в условии задания.

### 7.1. Генератор случайных чисел и воспроизводимость

```python
rng = np.random.default_rng(2026)  # генератор; 2026 — seed (зерно)
rng.random()                       # следующее случайное число
```

- **seed** задаёт всю последовательность случайных чисел. Тот же seed — те же
  числа, поэтому результат можно **воспроизвести**: перезапустил тетрадку —
  получил те же выборки. Без этого невозможно ни отладить код, ни сверить ответ
  с коллегой.
- Функция, которая делает что-то случайное, должна **принимать `rng`
  аргументом** и брать случайность только из него. Тогда вызывающий управляет
  воспроизводимостью: `f(..., np.random.default_rng(1))` дважды даст одно и то же,
  а `default_rng(2)` — другое.
- ⚠️ Если внутри функции взять случайность из другого места (`np.random.choice`
  без `rng`, `pop.sample(n)` без `random_state`), то переданный `rng` ни на что не
  влияет и воспроизводимость пропадает.

### 7.2. Выборка с возвращением и без

| | Без возвращения | С возвращением |
|---|---|---|
| Смысл | Вынули объект — он больше не участвует. Один объект в выборке не более одного раза | Вынули, записали, вернули обратно. Объект может попасть несколько раз |
| Пример | Опрос 500 разных жителей | Бросить кубик 500 раз |
| Простая случайная выборка из совокупности | ✅ так и делают | |
| numpy | `rng.choice(N, size=n, replace=False)` | `rng.choice(N, size=n, replace=True)` или `rng.integers(0, N, size=n)` |
| pandas | `df.sample(n, random_state=rng)` | `df.sample(n, replace=True, random_state=rng)` |

`rng.choice(N, size=n, replace=False)` возвращает **номера строк** — $n$ разных
целых чисел от $0$ до $N-1$. Строки по номерам берут через `df.iloc[номера]`.

⚠️ `iloc` — по **позиции** (0, 1, 2, …), `loc` — по **метке индекса**. После
фильтрации (`pop[pop["device"] == "app"]`) метки идут с пропусками, и номер
позиции уже не равен метке. Для случайных номеров нужен `iloc`.

Когда $n \ll N$ (500 из миллиона), выборки с возвращением и без почти не
отличаются: шанс вытащить один объект дважды ничтожен. Поэтому в Монте-Карло
(7.3) берут более быстрый вариант с возвращением.

### 7.3. Монте-Карло: как увидеть распределение оценки

Оценка — случайная величина (раздел 1). Её распределение можно увидеть
напрямую: взять много независимых выборок, по каждой посчитать оценку, посмотреть
на облако оценок. Это **метод Монте-Карло**.

Векторно: матрица номеров `(n_sim, n)`, каждая **строка** — отдельная выборка.

```python
idx = rng.integers(0, len(values), size=(n_sim, n))  # с возвращением, n ≪ N
samples = values[idx]            # матрица значений (n_sim, n)
samples.mean(axis=1)             # вектор из n_sim средних: по строкам
np.median(samples, axis=1)
samples.var(axis=1, ddof=1)
```

`axis=1` — «вдоль строки», то есть одна оценка на одну выборку.

### 7.4. Библиотечные функции из практики

| Задача | Код | Ловушка |
|---|---|---|
| Доля True | `mask.mean()` или `mask.sum() / len(mask)` | — |
| Частоты значений | `s.value_counts(normalize=True).sort_index()` | без `normalize` — счётчики, а не доли; без `sort_index` — порядок по частоте |
| Логнормальное распределение | `stats.lognorm(s=σ, scale=np.exp(μ))` | параметры **не** `(μ, σ)`: `s=σ`, `scale=e^μ` |
| Интеграл | `integrate.quad(lambda x: x * f(x), 0, np.inf)[0]` | возвращает пару (значение, погрешность) |
| Сколько элементов отсортированного `xs` ≤ x | `np.searchsorted(xs, x, side="right")` | `side="left"` считает строго `< x` |
| ECDF в scipy | `stats.ecdf(x).cdf.evaluate(t)` | — |
| Счётчики гистограммы | `np.histogram(x, bins=edges)[0]` | `density=True` уже делит на $n\Delta_j$ |
| Ширины интервалов | `np.diff(edges)` | — |
| Интеграл по сетке | `np.trapezoid(y, x)` | в numpy < 2 называлось `np.trapz` |
| Broadcasting | `x[:, None] - sample[None, :]` | матрица `(len(x), n)` всех разностей |

## Шпаргалка

| | Формула |
|---|---|
| Несмещённость | $M[\hat\theta_n]=\theta$ |
| Состоятельность | $P(\lvert\hat\theta_n-\theta\rvert>\varepsilon)\to0$ |
| MSE | $D[\hat\theta]+\text{bias}^2$ |
| Среднее | $\overline X=\frac1n\sum X_i$ |
| Дисперсия | $S^2=\frac1n\sum(X_i-\overline X)^2,\ \ M[S^2]=\frac{n-1}n\sigma^2$; $\ s^2=\frac1{n-1}\sum(\dots)^2$ |
| Доля | $\hat p=m_A/n$ |
| ECDF | $\hat F_n(x)=\#\{X_i\le x\}/n$ |
| Квантиль | $\hat x_\alpha=X_{([n\alpha]+1)}$ |
| Гистограмма | $h_j=n_j/(n\Delta_j)$ |
| KDE | $\hat f_n(x)=\frac1{nh}\sum K\big(\frac{x-X_i}h\big)$ |

## Мостик дальше

$\overline X$ — случайная величина со своим разбросом. На этом построены следующие
уроки: «насколько далеко $\overline X$ может уйти от $\mu$» (доверительные интервалы)
и «сколько нужно наблюдений для заданной точности» (объём выборки).
Длинный правый хвост чеков, который виден здесь, продолжим в уроке про выбросы.
