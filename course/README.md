# Курс «Специалист по Data Science» — рабочая тетрадь

## Сквозные данные

Раздел «Статистика» целиком идёт на одном синтетическом маркетплейсе:
`ds_course.marketplace.make_population()` — миллион заказов за месяц.
Мы сами задаём законы, по которым сгенерированы данные, поэтому любую оценку
можно сверить с истиной. В реальной работе такой возможности нет.

Установка и работа с решениями — в [README репозитория](../README.md).
